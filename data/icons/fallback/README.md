# Outpost's interface icons

Copies of the GNOME Adwaita icons Outpost's interface uses, renamed with an
`outpost-` prefix. Outpost uses these instead of the desktop's icon theme so it looks
the same everywhere: other themes, such as KDE's Breeze, lack some of these icons or
draw them in ways GTK 4 apps can't show.

`outpost-application-x-executable-symbolic.svg` is the placeholder shown while an
app's own icon loads.

From the Adwaita icon theme by the GNOME Project
(https://gitlab.gnome.org/GNOME/adwaita-icon-theme), licensed under either the
